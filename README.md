## Featured Project

### [RepoSpend](https://github.com/mehmetdemircs/RepoSpend)

RepoSpend is an open-source, local-first CLI and dashboard for understanding AI coding usage across repositories and tools.

It helps developers see which repositories, sessions, and tools are consuming AI coding tokens, with a focus on private, local-first analysis. The goal is to make AI coding usage easier to understand without requiring developers to upload prompts, source code, or session data by default.

RepoSpend is designed for questions like:

- Which repositories account for the most AI coding usage?
- Which sessions consumed the most tokens?
- How does usage vary across projects and tools?
- What patterns are visible across local development workflows?
